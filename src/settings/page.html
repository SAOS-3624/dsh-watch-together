本页只写本机 JSON。语音适配器在下一场陪看开始时挂载；聊天端口由聊天服务启动时读取，服务已在跑时需重启 DSH。台词/ASR 的 key 在“视频分镜”设置页里配。

位置与聊天

位置来源顺序：扩展上报 → 调试端口 → 系统媒体会话（SMTC）；都没有时才需要手动传 cursor。

声音

留空 = 台词只写进聊天记录，不念出来。

依赖与下载

缺少的依赖会出现官方下载按钮；插件只打开官方来源，不静默安装、不执行下载的文件。装好后回到本页点“重新检查”。

Python（悬浮窗）

  • Windows 从 python.org 下载，安装时勾选 “Add python.exe to PATH”。
  • 装完终端运行 python --version；没有悬浮窗时仍可用浏览器页面兜底。

浏览器扩展

  • Edge 打开 edge://extensions，开启“开发人员模式”，选择仓库的 extension/ 目录“加载解压缩的扩展”。
  • 扩展目录可从这里查看：extension/；不需要从商店安装。
  • 没有扩展时，仍可用调试端口或 SMTC 读位置；只是浏览器页面内播放不一定能上报。

ffmpeg / ffprobe

  • Windows：下载官方 zip，解压后把 bin 加进 PATH；或 winget install Gyan.FFmpeg。
  • macOS：brew install ffmpeg。建段和截图都依赖它们；没有 ffmpeg 时陪看无法生成图片。

dsh-video-storyboard

  • 陪看插件单向依赖它建段；缺它时工具会报错。先安装/启用分镜插件：分镜插件仓库。

语音适配器

  • 示例：examples/voice-edge-tts/；也可以填自己的 .mjs 路径或包名。
  • 适配器导入失败只会没声音，不会让陪看起不来；错误会出现在下一场开始时的 note 里。
