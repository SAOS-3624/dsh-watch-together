# Watch Together

Watch a video in sync with the user's real playback. Before each segment ends, the plugin delivers one storyboard image and its timed lines; the floating window carries speech, microphone input, and the chat history.

- `watch_together`: start watching, wait for the next segment, write lines
- Floating window: voice input/output, history, microphone
- Settings: browser debug port, chat port, window style

See the repository README for full usage and integration details.
