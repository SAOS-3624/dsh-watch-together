# 注意：必须装到**带 tkinter 的那个 Python** 里。有些发行版（例如微软商店版）

#
#   python -c "import tkinter, PIL, mss, numpy; print('ok')"

# 0.2.1 换了窗口实现（以 PR #15 的实时捕获管线为底稿），抓屏 / 模糊 / 透镜都在
# numpy 数组上算，所以 mss 和 numpy 从"可选"变成必需 —— 缺了窗口起不来，
# 不会再退化成纯色圆角面板。
